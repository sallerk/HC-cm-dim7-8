par_logs/ -- stdout of the worker processes of the parallel runs (see ../README.txt)
=====================================================================================================

stdout_cKKKK.txt   (40 files) stdout of "sage -python trans_enum.py 8 KKKK KKKK+49 cKKKK", started by
                   "run_par.py 8 50 7" (Stage B, transitive groups 16TKKKK ... 16T(KKKK+49)).  First line: g, n,
                   NrTransitiveGroups and the index range; then one line per pair (G, rho) whose group has
                   primitive degenerate types or an index divisible by 50: label, index j of rho, |G|, numbers of
                   type orbits, primitive orbits and primitive degenerate orbits, time (and total time); last
                   line: number of (G, rho) pairs and time.  stdout_c1801.txt and stdout_c1851.txt also contain
                   GAP information lines ("#I  Alternating recognition needed!").
stageC_wNNNNN.txt  (67 files) stdout of "sage -python stageC.py work NNNNN NNNNN+100 wNNNNN", started by
                   "run_parC.py 100" (Stage C, class indices NNNNN ... NNNNN+99): a progress line at every class
                   index divisible by 200; last line: number of cases and time.  stageC_w03400.txt and
                   stageC_w04800.txt also contain the GAP information line above.
The re-run of 2026-10-07 (../README.txt, section 7) reproduced all 107 files up to the timing values.

Not kept (intermediate files of the same runs, regenerated by every run):
  trans_g8_cKKKK.json, enum_g7_wNNNNN.json   chunk results; run_par.py and "stageC.py merge" combine them into
                   ../trans_g8.json and ../enum_g7.json.  Merging the chunk files reproduces the merged files byte for
                   byte, and splitting the merged files by index range reproduces every chunk file byte for byte.
  log_trans_g8_cKKKK.txt   written by trans_enum.py itself; identical to stdout_cKKKK.txt except for the GAP
                   information lines.
